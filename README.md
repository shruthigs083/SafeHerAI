# 🛡️ SafeHerAI — AI-Powered Women Safety Platform

**SafeHerAI** is an AI-powered women’s safety platform designed to support users during emergencies through SOS alerts, location tracking, incident reporting, and AI-assisted threat detection.

The platform brings together safety tools in one place to help users respond to potentially dangerous situations and access emergency resources quickly.

## ✨ Features

- **🚨 Emergency SOS:** Trigger an emergency alert during unsafe situations.
- **📍 Live Location Tracking:** Support location sharing to help trusted contacts identify the user's location.
- **👥 Emergency Contacts:** Manage trusted contacts for emergency assistance.
- **🎙️ Voice SOS:** Initiate emergency assistance using voice-based interaction.
- **🤖 AI Threat Detector:** Analyze potential threats using AI/ML-based threat detection.
- **📝 Incident Reporting:** Record and report safety-related incidents.
- **🔐 Evidence Vault:** Store incident-related evidence for future reference.
- **📞 Emergency Resources:** Provide access to relevant emergency helplines.

## ⚙️ Getting Started

### Prerequisites

- Python 3.10 or a compatible version
- pip package manager
- Git

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/SafeHerAI.git
cd SafeHerAI
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**
```bash
venv\Scripts\activate
```

**macOS/Linux**
```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to access the application.

## 🔒 Privacy & Safety

- Avoid committing passwords, API keys, personal information, or real incident evidence.
- Keep sensitive database files out of public repositories.
- Verify emergency contacts and API integrations before relying on them.
- SafeHerAI is intended as a supportive safety tool and should not replace official emergency services.
